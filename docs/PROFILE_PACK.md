# Ready-made profile pack

Fifteen profiles for the K2 HE (ISO), generated by `tools/make_profile_pack.py` into `profiles/` and
checked by `ProfilePackTest` (every key decodes, no gamepad key sits off the board, no target is used
twice, the Launcher `analog` block lists exactly the gamepad keys, every response curve is valid).
Copy the files into `Documents\Keychron Profiles`; the library picks them up. They are also importable
in the Keychron Launcher. Nothing here has been run on the keyboard yet: treat the numbers as a starting
point and tune them on the Actuation and Gamepad pages.

Units: travel values are in 0.1 mm (`18` = 1.8 mm).

## How the pieces fit

- **XInput mode is keyboard-wide, not per profile.** The app switches it for you when a slot contains
  gamepad keys ("Switch XInput with the profile" on the Gamepad page); the keyboard needs a cable replug
  for a mode change to take effect.
- **Typing is off in XInput mode.** A gamepad key stops typing its letter unless the "also type" bit is set.
  Keep a typing profile (the LoL ones) in another slot for chat.
- **The response curve is keyboard-wide too.** The `curve` stored in each file is what the Launcher uses;
  this app does not apply it on load. The recommended curve for each profile is listed below; set it on
  the Gamepad page, Curve view (presets Precise / Responsive match the ones named here).
- **What the keyboard can send as analog.** Two triggers (LT, RT) and the four directions of each stick.
  XInput face buttons, bumpers and the D-pad are plain on/off. So "pressure-sensitive face buttons" are
  done by sending the key's depth on a stick axis or trigger and binding that axis to the PS2 button in the
  emulator. A real DualShock 2 / 3 pad has 12 pressure buttons; this has at most 6 analog channels
  (LT, RT, and four stick directions), and only when the right stick is not needed for the camera.

| Profile | Keys | Curve |

| PC Analog WASD Actions | WASD = left stick, arrows = right stick, Space A, Ctrl B, E X, R Y, Q LB, F RB, Shift LT, Alt RT, C / V stick clicks, 1-4 D-pad, Tab Back, Enter Start | Precise |

Press lightly to walk, deeper to run. With the mouse and keyboard these work in games that accept a
controller alongside the mouse; in games that switch strictly between mouse and pad, the pad wins.

### Emulator recipes

**PCSX2** (Settings, Controllers; XInput or SDL source; sources: pcsx2.net controller docs and forum threads)
- Gas and brake: bind Cross / Square, or R2 / L2, to RT / LT. If gas jumps to 100 percent at half a press
  (reported on the PCSX2 forum with ordinary triggers), lower the analog sensitivity in the pad settings; the key's full 4 mm travel is the whole range.
- Pressure faces (PS2 Pressure Racing and PS2 Pressure Faces): bind Triangle to Right Stick Up (I),
  Square to Right Stick Left (J), Cross to Right Stick Down (K), Circle to Right Stick Right (L). Binding
  an analog axis to a pressure button is how people replace a trigger-bound Square in Metal Gear Solid 3;
  Shift+click a binding to set its strength. Check each in the on-screen pad tester.
- Pressure Modifier: bind it to Guide (Caps Lock in the profiles). While it is held, other buttons send the
  "Pressure Modifier Amount" (default 50 percent). Use it for light taps such as MGS3 grabs.
- Guide must not open the Xbox Game Bar: turn off "Open Xbox Game Bar using this button" in Windows
  Settings, Gaming. If the emulator does not see Guide, bind the modifier to R3 and map R3 off.

**RPCS3** (Pads, XInput handler)
- L2 / R2 are analog from LT / RT. Set the trigger thresholds to 0 for full range.
- Xbox-style pads have no pressure buttons in RPCS3, and I found no way to bind a face button to an axis
  there. Use "Pressure Intensity Button" = Guide (Caps Lock) with a percentage for light presses.
  For a true analog Cross you need a DualShock 3 driver path (for example DsHidMini or a virtual DS3),
  which the keyboard cannot provide.

**Dolphin**
- Map both "L" and "L-Analog" to the left trigger, and both "R" and "R-Analog" to the right trigger. The
  digital L / R then fire on a full press and the analog value gives light shield or partial brake.
  Start from Dolphin's automatic XInput mapping and only change the two trigger pairs.

**DuckStation / Project64 / Mupen64Plus**: start from the emulator's automatic XInput mapping; the face buttons
sit where an Xbox pad's would, so the defaults line up.

## Regenerating

```
python3 tools/make_profile_pack.py            # writes profiles/
python3 tools/make_profile_pack.py "<folder>" # writes somewhere else, for example Keychron Profiles
```

Edit the `PROFILES` list in the script to change a mapping; the numbers in `CURVES` and the per-key tuples
are in 0.1 mm.
